# Excel Chart Story – Data Analysis

## 📊 Project Overview

This project is an Excel-based data analysis and visualization task. The objective is to transform sales data into simple and meaningful charts that communicate important business insights.

The analysis focuses on product sales, monthly sales trends, regional sales contribution, and units sold.

## 🎯 Objectives

- Analyze total sales by product
- Understand monthly sales trends
- Identify the region with the highest sales contribution
- Identify the product with the highest units sold
- Present insights using simple Excel charts

## 📁 Dataset

The dataset contains the following columns:

- Month
- Product
- Region
- Units Sold
- Sales (₹)

## 📈 Visualizations

### 1. Product-wise Total Sales
**Chart Type:** Bar Chart

This chart compares total sales generated by each product.

### 2. Monthly Sales Trend
**Chart Type:** Line Chart

This chart shows how total sales changed from January to June.

### 3. Region-wise Sales Contribution
**Chart Type:** Pie Chart

This chart shows the contribution of each region to total sales.

### 4. Product-wise Units Sold
**Chart Type:** Bar Chart

This chart compares the total number of units sold for each product.

## 🔍 Key Insights

- Laptop generated the highest total sales.
- Mobile sold the highest number of units.
- June recorded the highest monthly sales.
- February recorded the lowest monthly sales.
- The West region contributed the highest total sales.

## 🛠️ Tools Used

- Microsoft Excel
- Excel Formulas
- Bar Charts
- Line Charts
- Pie Charts
- Data Analysis

## 📌 Conclusion

The project demonstrates how Excel can be used to convert raw sales data into meaningful visual insights. The charts make it easier to understand product performance, regional contribution, and monthly sales trends.
